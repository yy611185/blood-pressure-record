# 真机样本测试文件夹（拍照识别）

请把维乐高® 电子血压计的实拍照片放入本目录（或子目录），用于：
1. 开发期调参：验证 ML Kit OCR + 行结构解析的识别率；
2. 最终验收：需求文档要求"维乐高实测 ≥90%（20 张样本，三行全部正确）"。

## 命名约定（建议）

- 读数界面：`reading_<序号>_<条件>.jpg`，例如 `reading_01_daylight.jpg`、`reading_02_tilted.jpg`
- 待机界面：`standby_<序号>_<条件>.jpg`（用于验证"应提示而非错误读数"）
- 建议覆盖：不同光照（明亮/昏暗/反光）、不同角度（正对/倾斜）、不同距离（近/中/远）、不同数值组合

## 说明

- 本目录已在 `.gitignore` 中排除，照片不会进入版本库，避免隐私泄露。
- 样本就位后告知我，我会用脚本批量跑识别并输出准确率报告。
