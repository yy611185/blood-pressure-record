# 趋势图全屏与 Review 修复

实施日期：2026-10-03。基于 v2.1.3 的趋势图改造，版本已迭代至 v2.2.0（versionCode 39）；应用内与仓库更新说明已同步，尚未发布到 GitHub。

## 已实现

- 趋势页的“全屏”入口；手机请求横屏，返回时恢复进入前的方向策略。平板、折叠屏与分屏按窗口布局。
- 沿用 7 天、30 天、全部自然日筛选，统一显示每次测量的双折线；按用户反馈移除每日范围柱图及入口。
- 主副图共享时间窗口和选择，血压与脉搏各自使用独立纵轴。脉搏副图可隐藏。
- 点击、长按拖动查看真实节点，联动十字线与读数栏同步；上一条、下一条、明细、恢复、回到最新。
- 横屏仅保留紧凑顶栏，时间、血压与脉搏显示在右上角，导航与恢复等操作移入顶栏菜单。主图使用剩余高度，首次进入默认隐藏脉搏副图，可独立开启。
- 竖屏读数不再使用大面积彩色卡片，保留时间、血压和脉搏；所有记录操作保持同一水平滚动行。
- 横屏纵轴按绘图区高度和字体增加刻度；顶栏“时分”切换具体时间刻度，小时细节视窗自动显示时分。
- 宽窗口的侧边明细与窄窗口的底部明细，定位所选原记录并可进入历史详情。
- SavedStateHandle 保存范围、粒度、指标、选中点及时间锚点、脉搏开关、全屏状态和绝对视窗。配置重建与进出全屏复用同一个控制器。

## 数据与操作约定

每个 Session 已保存代表值参与一次统计，不修改原始记录，也不重新计算历史代表值。期间平均基于完整 Session 集合，脉搏只统计有值的记录；无记录的日期留空。领域模型保留旧 DAILY/DAILY_RANGE 数据兼容，但页面状态统一使用 RAW，旧保存状态通过测量时间映射到实际记录。

切换日期范围清除选择、明细和旧视窗。新增记录不会把正在查看的历史窗口拉回最新位置。横屏脉搏开关与竖屏开关分别保存，时分选项、选中记录与绝对时间窗口在重建后恢复。

“恢复”与双击共用复位入口，清除选择并回到默认视野。“回到最新”保持时间跨度，移动到最后一次真实测量。上一条、下一条仅在目标不可见时调整位置。缩放和平移不改变标注为“期间平均”的统计口径。

绘制、手势、视窗数学拆分为独立文件。统计使用完整数据，抽样只用于绘制并保留极值与缺测边界。连续段从原始序列生成，抽样产生的时间间距不会制造缺测。折线使用真实时间坐标直线连接，再裁剪到绘图区；选中节点始终按真实血压单独补画。

全屏使用项目既有 Material 3 主题和数字字体，保留系统字体缩放和安全区。工具选项与竖屏记录操作可水平滚动，右上读数可随大字体换行；横屏没有底部操作栏或强制最小高度的滚动容器。

## 实机验证

1. 在趋势页缩放、拖动并选中一条历史记录，再进入全屏并返回，查看视窗与选择是否保持。
2. 长按拖动血压图及脉搏图，确认同一时间的读数联动；脉搏缺失时显示“—”。
3. 切换“时分”并缩放至小时范围，核对具体时间；确认没有每日范围柱图入口。
4. 点击明细并进入原记录，返回后确认图表位置保持；检查上一条、下一条、恢复和回到最新。
5. 在大字体及深色模式查看全屏的读数、图表和操作；隐藏脉搏副图后确认主图扩大。
6. 用系统返回退出全屏，确认方向恢复；如有平板或分屏，确认不依赖强制旋转也能查看详情。
