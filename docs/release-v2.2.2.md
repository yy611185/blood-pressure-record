# 血压记录 v2.2.2 更新说明

日期：2026-10-07。版本：2.2.2；versionCode：41。

本次更新为现有暖色界面增加轻量过渡，让滚动、选项切换、打卡和录入操作的状态变化更自然。

## 本次调整

- 底部导航随滚动收起：向下浏览时缩小为左下角的新增按钮，向上回看时自动展开。收起后仍可新增测量，轻微滚动不会反复切换，页面内容不会因底部留白变化而跳动。
- 历史与趋势选项增加颜色过渡；历史日期选中时有轻微反馈，月份标题淡入淡出。
- 首页小压的对话文字、最近记录加载与服药打卡增加短暂过渡，打卡后显示勾选反馈。
- 第三组及以后的读数平滑新增和删除，平均血压与高风险提示自然出现。保留至少两组、最多 20 组的录入规则。
- 读数与补充情况、对应标题淡入淡出；保存时在固定尺寸按钮内显示小型进度环和“正在保存…”。
- 折叠箭头平滑旋转，可点击数据卡片增加轻量按压反馈，“恢复跟随系统”按钮平滑显示或隐藏。

## 动画与兼容性

常用过渡约 120–180ms，底部导航约 260ms，新增动画跟随 Android 系统动画设置。主要使用颜色、透明度和图层位移，局部新增内容使用展开或收缩。

趋势曲线、数据刷新、时间窗口、缩放、平移、十字线与横屏脉搏副图高度保持直接响应；历史列表不增加整列表动画。当前布局、配色、字号、导航、血压计算、数据库结构、草稿和备份格式保持原有契约，核心依赖版本不变。
