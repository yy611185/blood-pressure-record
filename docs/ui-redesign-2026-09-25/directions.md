# UI 重构：方向探索

状态：视觉方向待用户选择，尚未开始应用界面改造。

## 已确认

先比较视觉效果图，再实现。按设计系统、核心路径、其余界面、整体验收与发布推进。优先独立录入效率、趋势理解、视觉统一。

## 七个初始候选

1. 家用测量仪：清楚的数字分区、稳定位置的操作键；适合在设备与手机间转录。
2. 公共导视：高对比文字、简明方向与大触控区域；一眼找到下一步。
3. 个人记录簿：日期索引与对齐的数据行；便于核对原始读数。
4. 日程台历：今天与下一次行动优先；适合形成记录习惯。
5. 气象简报：结论先行、变化图随后；支持理解一段时间的变化，不借用天气图标表示健康。
6. 图书目录：清晰分组和逐级检索；历史与数据管理容易定位。
7. 计量刻度：共享基线、量值标签与严格对齐；建立跨页面的数字辨识度。

以上跨设备、导视、纸本文书、时间组织与数据图形；不沿用现有暖色圆卡片体系。所有方向遵守 Android 原生交互与大字重排。
