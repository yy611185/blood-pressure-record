# 血压记录 v2.3.5

修复 Android 应用内更新的“下载已完成，但点击安装更新没有反应”问题：

- 安装失败、APK 重新校验异常和未授予未知应用安装权限时，错误直接显示在更新弹窗与设置页的安装区域，不再藏在弹窗背后的 Snackbar 中。
- 点击安装立即显示校验/授权进度；完成或失败时恢复操作按钮，避免无反馈和重复点击。
- 移除“必须保持更新提示弹窗可显示”才能继续安装的状态门控；从系统授权页面返回后仍可继续发起安装。
- 安装请求状态不再跨进程恢复为永久挂起，避免系统回收进程后按钮失效。
- 为 FileProvider content URI 补充 ClipData 读取授权，常规 APK 安装 Intent 没有处理程序时尝试系统 ACTION_INSTALL_PACKAGE 入口。
- 保持正式签名、包名、版本号、SHA-256 及系统安装器验证，不绕过系统授权；不更改血压数据、数据库或备份格式。

请在手机安装 v2.3.4，然后更新到 v2.3.5 验证；没有运行模拟器或仪器测试。
