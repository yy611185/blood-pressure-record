# 血压记录 v2.3.1 更新说明

日期：2026-10-11。版本：2.3.1；versionCode：42；包名：`com.yang.bloodpressure`。

## 功能与交互

- 趋势图的 7 天、30 天、全部记录可自由组合“每次测量 / 每日平均”，普通页与横屏全屏共用粒度、时间视窗与选点，脉搏图继续同步。
- 尚无主动偏好时，7 天默认每次测量，30 天和全部默认每日平均；主动选择的粒度保存在已有 DataStore，切换范围、旋转及重新进入页面继续使用。
- 每次测量按真实时间显示各次 Session 已保存的代表值；每日平均按设备本地自然日，对当天各次 Session 代表值等权计算并取整。脉搏只对有值的 Session 求平均，没有记录的日期不补点。
- 每日节点显示日期、平均血压、有效测量次数、平均脉搏及高风险提示；不把绘图时间戳当作测量时分。明细显示当天参与统计的记录，可继续打开原始详情。
- 切换粒度尽量保留绝对时间视窗，选中测量映射到所属日期，切回时优先恢复原 Session；映射节点在窄窗外时只平移至该节点，保留窗口宽度并停留在对应历史日期。缩小普通圆点、减少密集节点重叠，选中点更清楚，采样保留高风险与峰谷。

## 数据兼容

期间、早晚与昼夜统计仍使用全部 Session 已保存的代表值，期间平均不会对每日平均再次等权计算。高风险提示继续反映原记录，平均正常不会取消当日异常提示。

数据库 Schema、数据库版本、Session 代表值和备份格式不变，不改写历史记录。保留暖色与深色界面、大字、指标选择、目标线、模块折叠、历史详情、Dock 动画及导入导出。

## 真机验收

1. 覆盖安装，确认版本 2.3.1、原历史记录完整；趋势中切换六种范围与粒度组合。
2. 同一天有多次记录时核对每日血压和脉搏平均，检查缺失脉搏、缺测日期及高风险提示；明细应列出参与统计的原记录。
3. 选中一个 Session、缩放和平移后切换每日平均，再切回每次测量，检查视窗、原 Session 和脉搏选点联动。
4. 主动选择粒度后切换范围、退出再进入、旋转及进出全屏，确认偏好和查看位置；检查深色、大字与密集数据。
5. 确认期间、早晚、昼夜统计、指标与目标线、折叠、历史跳转、Dock 及备份入口仍正常。
