### `AUD-01` · 趋势页选点操作栏「复位视野」文字截断（`P0`）
- **决策轮次**：第一轮 `D1-1`
- **最终决策**：**`ACCEPTED`**（附严格约束）
- **决策理由**：实机截图 #4/#5 与源码几何测算双重证实：M3 `TextButton` 强制 `64.dp` 最小宽使 5 项操作在 `393dp` 常规屏 1.0x 下溢出 `15–17dp`，将「复位视野」裁为「复位视」，属明确 P0 客观缺陷。
- **最终实施方案**：
  - 在 `ui/common/AppComponents.kt` 新增轻量紧凑操作胶囊组件（脱离 `TextButton` `64.dp` 最小宽约束，保持 `minWidth = 48.dp`、`minHeight = 48.dp`、合理水平内距）；
  - 在 `ui/history/TrendScreen.kt` 的 `TrendSelectionReadout` 改用 `FlowRow` 自适应布局，移除无提示的 `horizontalScroll`；
  - 保留「复位视野」完整文案；正常字号下尽量单行显示，大字号或窄屏允许自然换行；**严禁通过缩小字号或缩小触控热区强行维持单行**。
- **关联规范**：`DESIGN-SYSTEM-STANDARD-FINAL.md` §8.1、`§11`
- **实施优先级**：**P0 · 阶段一（WP-1.4）**
- **验收标准**：`360dp / 393dp` 屏 1.0x 下 5 个按钮完整单行显示、「复位视野」零截断；`1.5x–2.0x` 下自然折行、全部触控热区 `≥ 48dp × 48dp`。

### `AUD-02` · 浅色主题 `outline` 对比度不足与数字输入框硬编码边框（`P0`）
- **决策轮次**：第一轮 `D1-2`
- **最终决策**：**`MODIFIED`**
- **采纳 / 调整 / 拒绝明细**：
  - **采纳**：新增浅色语义描边色 `WarmOutline = Color(0xFF8A8177)` 赋给 `LightColors.outline`；删除 `CompactNumberField` 中 `colors.background.red < 0.5f` 主题嗅探与硬编码 `Color(0xFFB3A99D)`，统一读取 `MaterialTheme.colorScheme.outline`。
  - **保留**：保留 `LightColors.outlineVariant = WarmDivider (#E3DDD5)` 专供装饰性分割线及其他全部品牌色不变。
  - **拒绝**：拒绝 03/04 号报告提出的“将深色模式 `DarkColors.outline (#7F7973)` 提亮至 `#9A9085`”（现有 `#7F7973` 实测相对 `#26201C` 为 `3.74:1`，已达 WCAG `≥3.0:1`）。

- **实施优先级**：**P0 · 阶段一（WP-1.1）**
- **验收标准**：通过对比度单元测试与实际背景复核，浅色 `outline` 相对 `surface (#FFFDFA)`、`background (#FAF6EF)`、`surfaceVariant (#F2ECE3)` 对比度均 `≥ 3.0:1`；`CompactNumberField` 无硬编码边框色与背景色嗅探。

### `AUD-03` · 减弱动态效果下自定义 `indication = null` 控件失去按压反馈（`P0`）
- **决策轮次**：第一轮 `D1-3`
- **最终决策**：**`MODIFIED`**
- **采纳 / 调整 / 拒绝明细**：
  - **采纳**：修复 `Modifier.pressableScale` 在 `LocalReducedMotion.current == true` 时完全无反馈的问题，并补齐 `WheelTimePicker` 滚轮相邻可点击项在常规与减弱动效下的按压反馈。
  - **调整**：采用 **`0ms` 瞬时 `alpha = 0.84f`** 反馈方案（保持 `pressableScale` 签名与正常模式弹簧缩放动画不变，不扩大公共组件重构范围）。

- **关联规范**：`DESIGN-SYSTEM-STANDARD-FINAL.md` §10.2
- **实施优先级**：**P0 · 阶段一（WP-1.3）**
- **验收标准**：开启系统“移除动画 / 减少动态效果”后，点按底部 Dock、主次按钮、分段胶囊、日历格、服药打卡及时间滚轮，均具有即时可辨识的按压反馈且无动画协程残留；不同背景色下反馈均清晰可辨。
