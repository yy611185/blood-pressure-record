# 备份加密设计说明

当前 Excel v2/v3 备份格式保持明文 `.xlsx`，用于维持现有导入兼容性和用户可迁移性。明文文件可能包含姓名、年龄、目标血压、测量时间、原始读数、症状、备注和提醒设置；应用只在用户主动选择文件位置后写出，不会上传服务器。

## 后续格式

未来增加加密备份时，建议新增独立格式版本，不修改 v2/v3 的字段含义：

- 外层使用独立文件扩展名和固定魔数，标识版本、KDF 参数、盐、随机数和认证标签。
- 密钥由用户输入的口令派生，优先使用 Android Keystore 保存设备侧密钥包装材料；口令本身不落盘。
- 使用经认证加密的 AES-GCM，随机数每个文件唯一；密文覆盖完整压缩包，不能只加密单个工作表。
- 在解密前限制文件大小，在解密后继续执行 ZIP 条目数、单条目/累计解压量、压缩比、XML 和业务记录上限。
- 认证失败、口令错误、格式版本不支持和业务校验失败必须分别提示；任何失败都不能写入 Room 或 DataStore。
- 新格式导出/导入与现有明文格式并存一段时间，完成迁移验证后再考虑默认格式切换。

这份设计不等于当前版本已经加密；当前版本界面会在每次导出前明确提醒文件未加密。
