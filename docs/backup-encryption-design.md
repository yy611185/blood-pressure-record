# 备份加密设计说明

当前 Excel v2/v3 备份格式保持明文 `.xlsx`，用于维持现有导入兼容性和用户可迁移性。明文文件可能包含姓名、年龄、目标血压、测量时间、原始读数、症状、备注和提醒设置；应用只在用户主动选择文件位置后写出，不会上传服务器。

## 已实现的加密容器（.bpx）

数据管理页导出时可选「加密导出」，生成 `.bpx` 加密容器；导入时自动识别并提示输入口令。实现位于 `BackupCrypto.kt`：

- 文件布局：magic `"BPRX"`(4B) + 格式版本(1B) + KDF 标识(1B) + 迭代次数(4B 大端) + 盐(16B) + nonce(12B)，共 38 字节头部；随后为 AES-256-GCM 密文（含 128 位认证标签）。
- 密钥派生：PBKDF2-HMAC-SHA256，310_000 次迭代，256 位密钥；口令不落盘。
- 认证加密：AES-256-GCM，随机数每文件唯一；整个头部作为 GCM AAD，防止参数被替换；密文覆盖完整 xlsx 压缩包。
- 错误区分：口令错误/文件被篡改（认证失败）、容器损坏、版本不支持分别提示；任何失败都不写入 Room 或 DataStore。
- 解密后的内容继续执行原有 ZIP 条目数、单条目/累计解压量、压缩比、XML 实体和业务记录上限校验。

## 明文格式并存

明文 v2/v3 导出/导入与加密格式并存；明文导出前界面会明确提醒文件未加密。完成迁移验证后再考虑默认格式切换。
