# 血压记录 v2.2.1 更新说明

- 横屏趋势页的三点操作菜单移到左侧“时分”右边，时间范围、指标、时分与记录操作集中排列。
- 右上角继续紧凑显示测量时间、血压和脉搏；图表保留主要空间。小屏或大字体下，左侧工具栏可横向滚动。

- 纵轴按可用高度增加刻度，横轴支持具体时分，缩放可进入小时细节；竖屏读数精简，恢复与其他记录操作保持同行。

- 用药数据可以独立选择恢复；超过 5000 条记录自动按完整测量分卷，支持明文 Excel 和加密备份逐卷保存、恢复。
