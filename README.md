# 家庭血压记录 · Blood Pressure Record

> 一个**本地优先**的血压记录 Android 应用——为家庭成员（尤其是中老年人）设计：不注册，健康数据保存在手机里。App 仅为检查软件更新联网，安装包交由外部浏览器下载。

## 一、这是给谁用的？

**给血压需要被记录的人，以及记录他们的家人。**

- 界面大、字号可调，面向中老年用户优化
- 血压记录、历史、提醒与备份可离线使用：**不注册账号、不做健康数据云同步**
- 一次测量，自动计算平均值、分级、趋势，家人不用对着数字发愁
- 数据自由：随时导出 Excel 备份，换机一键恢复

> ⚠️ 应用内的血压分级仅供参考，**不替代医疗诊断**。如有异常请咨询医生。

## 三、核心功能

| 功能 | 说明 |
|---|---|
| 📝 一次记多组 | 每次新增至少填写两组收缩压和舒张压，脉搏选填，自动计算全部有效组的平均值，输入后可直接保存 |
| 🏷 自动分级 | 按《中国高血压防治指南》成人诊室标准分级：正常 / 正常高值 / 1–3 级 + 偏低提示 |
| 🗓 首页周卡 | 周一至周日逐日展示平均高压与低压的区间，同时显示本周均值和连续记录天数 |
| 📅 历史日历 | 按月查看、详情、编辑、删除、**撤销** |
| 📈 趋势图 | 7/30/180/365 天/全部自由切换每次测量与每日平均，记住粒度偏好；提供横屏全屏、联动十字线、缩放、明细追溯和期间/早晚/昼夜平均 |
| 💊 服药提醒 | 晨晚测量提醒可分别设置；按药品设置每日服药时间，支持打卡和写入选定的系统日历（需授权） |
| 📲 桌面小部件 | 不打开 App 也能看到最新血压与今日进度 |
| 💾 Excel 导入导出 | v6 完整备份测量、补充情况、设置和用药数据，兼容读取 v2–v5 |
| 📄 医生报告 PDF | 选择 7/30/90 天或自定义周期，本机生成 A4 摘要和逐日明细；预览中调整隐私，可分享、保存、打印或保存摘要图片 |
| 🔐 加密备份 | 可选 .bpx 加密导出：AES-256-GCM + 口令派生密钥，导入需相同口令 |
| 📦 软件更新 | 自动或手动检查版本，支持 3 天后再提醒、跳过版本，跳转浏览器下载后由系统覆盖安装 |

- 支持 Excel (.xlsx) 格式导入和导出；格式 v6 保留自动时间段、两项补充情况、历史平均值/策略和完整用药数据，并向后兼容 v2–v5。
- 导出文件包含使用说明、测量记录、全部原始读数、用户资料、药品、每日服药时间、打卡历史和导出信息。
- 文件交给用户选择的 Android 文件位置或文件提供方；应用不会自行上传服务器。
- 即使暂无测量记录，也可导出用户资料与设置。
- 测量或用药数据超过单卷条数上限时会自动分卷。请依次保存各卷 .xlsx 或 .bpx，从首卷恢复资料与设置，再逐卷恢复测量及用药数据。暂停后可在同一页面继续。若进程重建导致导出中断，请重新导出全部卷，并检查上次所选位置中的未完成文件。
- 可选择明文 Excel 或口令加密的 .bpx；两者都可能包含姓名、年龄、血压记录、症状、备注、提醒和用药数据，请妥善保存。
- 导入会先生成预览和统计信息，确认后才写入。可分别选择测量记录、用户资料、显示设置、提醒设置和用药数据。提醒设置包含服药提醒总开关，旧备份缺少该字段时沿用本机设置。
- 导入会拒绝明显的未来测量时间、重复记录 id、损坏或超过大小/解压安全上限的 xlsx；被跳过的记录不会写入。

### 导出医生报告

从“我的 → 数据管理 → 导出医生报告”进入，选择含今天的近 7、30、90 个本地自然日，或选择不超过 365 天的自定义日期范围。在选期页设置是否包含姓名与年龄、备注和药品。姓名与年龄每次进入时默认隐藏。预览页也可调整这三项，更改后须更新预览才能输出。

检查 PDF 页面后，可通过系统分享面板分享、选择文件位置保存 PDF、调用 Android 打印服务，或保存 150 DPI 的摘要页 PNG。图片仅包含摘要页，完整测量与长备注请查看 PDF 的明细及补充页。打印设备和文件保存位置由系统提供。

报告包括平均血压、早晚均值、脉搏、有效天数与测量次数、趋势、每日分级、逐日明细、备注和现有用药信息。同日多次测量逐次保留，凌晨及下午测量、长备注等放入补充明细。没有测量记录时提示先记录；不足 3 个有效日时标注“测量天数较少，统计仅供参考”。

现有数据无法可靠区分家测与诊室，报告明确注明分级与参考线采用诊室标准。用药仅列当前药品信息及保留的打卡次数，不推算依从率、漏服或调药历史。报告仅供参考，不替代医疗诊断。生成不联网，不改变 Room v9 或备份 v6；报告不用于备份恢复。

报告模板可选择“家庭血压报告”或“家庭血压 7 日监测”。7 日模板首日计入、全部时段参与总体统计，有任一次记录即为有效日；早晚明细各显示当天该时段的均值，多次测量的逐次记录保留在补充页。周期须恰好 7 个自然日。

实现边界、验证命令及待完成的真机验收见 [医生报告开发与验收说明](./docs/specs/doctor-report.md)。

## 四、你的数据安全（请放心）

1. **健康数据存于本机**。启用服药日历同步时，服药时间会写入你选定的日历，该账户可能同步或共享日程。日程默认只显示「服药提醒」，你可以为选定的日历开启药名和剂量。应用发出的服药通知使用通用隐私提示（锁屏与通知栏均不显示药名或剂量），点按通知后可在应用内核对具体药品与时间再确认打卡。软件更新模块只请求版本元数据。
2. **系统自动备份已关闭**：Room / DataStore / 健康数据均被排除在 Android 云备份与换机迁移之外。
3. **备份由用户主动导出**。在“我的 → 数据管理”选择明文 Excel 或口令加密的 BPX，然后选择保存位置。
4. **日历权限可选**：仅当你在设置中开启"服药提醒写入系统日历"时才申请 READ/WRITE_CALENDAR；关闭后不再使用。
5. **卸载即失**：未主动导出的数据卸载后无法找回——建议定期导出备份。
6. **软件更新联网**：更新服务及 Cloudflare 可能获得 IP 地址、请求时间、路径和基本请求日志。自动检查默认开启，可在“我的 → 使用指南与更新”关闭；主动打开浏览器或 GitHub 备用入口后，下载请求由浏览器发出。

## 五、快速开始

### 安装

- **获取方式**：通过 [GitHub Releases](https://github.com/yy611185/blood-pressure-record/releases) 下载最新自签名 Release APK（首次安装需允许"未知来源"）
- **发布规则**：正式 APK 在 GitHub Releases 和 HTTPS 更新服务分发，AAB 放在 GitHub Releases；源码仓库不保存安装包
- 最低支持 **Android 8.0 (API 26)**，建议 Android 10+

### 第一次使用（3 步）

1. 点击底部 **＋** 新增记录，填写至少两组高压和低压后保存。测量时段由时间自动识别。
2. 在“我的”中按需填写姓名、年龄和个人达标值。趋势页可查看目标达标率。
3. （可选）在“我的 → 提醒与服药”开启晨间或晚间测量提醒并管理服药计划。

### 换手机迁移

1. 在旧手机的“我的 → 数据管理”导出 .xlsx 或加密的 .bpx，并将全部分卷传到新手机。
2. 在新手机的同一页面选择“从备份文件恢复”，逐卷预览并确认导入范围。

### 软件更新

- “我的 → 使用指南与更新”可手动检查最新版本，查看最近更新说明及上次成功检查时间。
- 自动检查默认开启；成功后 24 小时内不重复自动请求。可选更新可以延后 72 小时或跳过该版本，手动检查不受这些设置限制。
- 发现新版本后，点击“前往浏览器下载更新”；App 优先打开清单中通过安全校验的香港直连镜像，没有可信直连镜像时回退原主下载地址。下载完成后打开 APK，按 Android 系统提示覆盖安装，无需卸载旧版。
- 成功打开浏览器后关闭提示，并将该版本提醒延后 72 小时；立即返回或重启 App 不会再次自动弹出相同版本，手动检查及更高版本不受影响。是否已更新始终根据实际安装的 versionCode 判断。
- 版本检查失败会显示失败及重试入口，不显示“已是最新版本”；[GitHub Releases 备用下载](https://github.com/yy611185/blood-pressure-record/releases) 在接口失败时仍可访问。
- 必要更新提示不会阻止离线记录、历史、提醒或备份。录入、编辑及备份等操作期间会暂缓自动弹窗。
- 开发说明及待完成的浏览器下载、系统覆盖安装实机验收见 [docs/specs/in-app-updates.md](./docs/specs/in-app-updates.md)。

## 六、技术栈（为什么是这些）

| 技术 | 用途 | 为什么 |
|---|---|---|
| Kotlin | 开发语言 | 官方首选，空安全 |
| Jetpack Compose + Material 3 | UI | 声明式 UI，主题/无障碍友好，适配三键导航与手势区 |
| MVVM + Repository | 架构 | 数据层与 UI 解耦，便于测试 |
| Room (v9) | 本地数据库 | 编译期 SQL 校验 + 迁移框架；**明文存储**（依赖系统 FBE 加密，详见隐私节） |
| DataStore | 设置存储 | 替代 SharedPreferences，Flow 响应式 |
| Coroutines + Flow | 异步 | 主线程安全，数据库查询响应式 |
| Apache POI (5.5.x) | Excel 导入导出 | 保留原始读数结构、多工作表；导出 v6，支持读取 v2–v6 |
| Glance | 桌面小部件 | Compose 风格的小部件 API，与 UI 同构 |

### 构建

```bash
./gradlew assembleDebug        # Debug APK（applicationId 带 .debug 后缀）
./gradlew assembleRelease      # Release APK（未配置签名时产出 unsigned 包）
./gradlew bundleRelease        # Google Play AAB
```

Release 签名通过环境变量注入（**绝不回退 Debug 密钥**）：

```bash
export BP_RELEASE_STORE_FILE=/path/to/release.jks
export BP_RELEASE_STORE_PASSWORD=...
export BP_RELEASE_KEY_ALIAS=bloodpressure
export BP_RELEASE_KEY_PASSWORD=...
```

产物：`app/build/outputs/apk/release/app-release.apk`、`app/build/outputs/bundle/release/app-release.aab`

### 测试

```bash
./gradlew test                  # 单元测试（JVM，快）
./gradlew connectedAndroidTest  # 仪器测试（需设备/模拟器）
./gradlew :baselineprofile:generateBaselineProfile  # 性能基线
```

覆盖范围（20+ 测试类）：平均值/分级/高风险规则、趋势图数学、月历布局、提醒时间计算、表单逻辑、Repository 保存读取、Excel 备份往返、数据库迁移。

### 已知限制（诚实声明）

- 健康数据在本地**明文存储**（Room，依赖 Android 全盘加密）；导出可选**明文 Excel** 或**口令加密的 .bpx 容器**
- 换机时手动恢复 .xlsx 或 .bpx 备份
- 血压分级采用《中国高血压防治指南（2024年修订版）》成人诊室标准，其他国家/地区标准可能不同

### 维护与兼容性约束

- Room 当前版本为 v9；新增字段或表必须提供显式迁移，禁止 destructive migration/fallback。修改记录更新逻辑时不得用 `REPLACE` 重建现有 session。
- Excel 当前导出 v6，导入须兼容 v2–v6；改变字段、派生平均值或风险阈值前先更新对应往返测试和迁移说明。
- 正式 `applicationId` 为 `com.yang.bloodpressure`，首次正式分发后不可更改；Release 未配置正式签名环境变量时仅生成 unsigned 产物，绝不回退 Debug 密钥。
- 本应用保持本地优先、无登录、无健康数据上传；网络权限仅用于版本元数据检查，安装包下载由外部浏览器处理。
- 血压分级与高风险提醒是两套规则：3 级分级不自动等于高风险提醒；修改阈值必须同步更新领域测试和历史迁移逻辑。
- 发布前至少执行 `testDebugUnitTest`、`lintDebug`、`assembleDebug`、`assembleRelease`，并在具备设备时执行 `connectedDebugAndroidTest`；使用 `apksigner verify` 检查 APK 签名、`jarsigner -verify` 检查 AAB 签名。
